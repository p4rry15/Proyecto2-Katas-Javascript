# Proyecto2-Katas-Javascript# Entrega de ejercicios de JavaScript

## Descripción del proyecto

Este repositorio contiene una recopilación de ejercicios realizados en JavaScript. El objetivo principal del trabajo es practicar los conceptos básicos y avanzados del lenguaje, además de trabajar con el DOM y con funcionalidades modernas de ES6.

A lo largo de los ejercicios se han utilizado variables, arrays, objetos, funciones, bucles, condicionales, métodos de arrays y manipulación de elementos HTML mediante JavaScript. También se han incluido ejercicios de destructuring, spread operator, map, filter y otros recursos propios de JavaScript moderno.

## Estructura del proyecto

El proyecto está organizado en tres carpetas principales:

```txt
ejercicios-basicos-avanzados/
ejercicios-dom/
ejercicios-ES6/
```

### `ejercicios-basicos-avanzados/`

En esta carpeta se encuentran los ejercicios principales de JavaScript, desde los conceptos más básicos hasta ejercicios más avanzados.

Incluye prácticas sobre:

- Declaración de variables.
- Uso de tipos de datos.
- Operaciones básicas.
- Condicionales.
- Bucles `for`, `for...of` y `for...in`.
- Arrays y objetos.
- Funciones.
- Búsqueda y filtrado de información.
- Manipulación de datos dentro de arrays.
- Ejercicios de lógica con películas, canciones, personajes, usuarios y otros datos.

Esta parte sirve para reforzar la lógica de programación y aprender a resolver problemas paso a paso usando JavaScript.

### `ejercicios-dom/`

En esta carpeta se encuentran los ejercicios relacionados con el DOM.

Cada ejercicio tiene su propio `index.html` y su archivo `script.js`, lo que permite probar directamente el funcionamiento en el navegador.

Incluye prácticas sobre:

- Selección de elementos con `querySelector` y `querySelectorAll`.
- Creación dinámica de elementos HTML.
- Inserción de contenido en la página.
- Modificación de elementos desde JavaScript.
- Eventos de usuario.
- Creación de listas dinámicas a partir de arrays.

Esta parte está enfocada en entender cómo JavaScript puede interactuar con una página web.

### `ejercicios-ES6/`

En esta carpeta se encuentran ejercicios centrados en funcionalidades modernas de JavaScript introducidas en ES6 y versiones posteriores.

Incluye prácticas sobre:

- Destructuring de objetos y arrays.
- Spread operator.
- Métodos de arrays como `map`, `filter` y `reduce`.
- Funciones flecha.
- Trabajo con arrays de objetos.
- Ejercicios combinados con HTML y JavaScript.

Esta parte permite escribir código más limpio, moderno y parecido al que se utiliza actualmente en proyectos reales.

## Tecnologías utilizadas

- HTML5
- JavaScript
- Navegador web
- Visual Studio Code

## Cómo ejecutar los ejercicios

Para ejecutar los ejercicios no es necesario instalar dependencias externas.

### Ejercicios JavaScript básicos y ES6 sin HTML

Los archivos `.js` pueden ejecutarse de dos formas:

1. Abriéndolos en Visual Studio Code.
2. Ejecutándolos con Node.js, si está instalado:

```bash
node ejercicio1.js
```

También se pueden revisar directamente desde el editor y comprobar los resultados mediante `console.log`.

### Ejercicios DOM

Para los ejercicios de DOM hay que abrir el archivo `index.html` correspondiente en el navegador.

Después, se puede abrir la consola del navegador con `F12` para ver los resultados y comprobar el funcionamiento del archivo `script.js`.

## Objetivos del trabajo

Los objetivos principales de esta entrega son:

- Aprender y practicar la sintaxis básica de JavaScript.
- Entender el uso de variables, arrays, objetos y funciones.
- Practicar bucles y condicionales para resolver ejercicios de lógica.
- Utilizar métodos modernos de arrays.
- Aprender a manipular el DOM desde JavaScript.
- Organizar los ejercicios por bloques según el contenido trabajado.
- Mejorar la forma de razonar y solucionar problemas con código.

## Contenido de la entrega

La entrega incluye:

- 42 ejercicios de JavaScript básico y avanzado.
- 5 ejercicios de manipulación del DOM.
- 9 ejercicios de JavaScript ES6.
- Archivos HTML necesarios para los ejercicios que trabajan con el navegador.
- Archivos JavaScript separados para mantener una estructura clara.

## Conclusión

Con este trabajo hemos practicado diferentes partes importantes de JavaScript, empezando por conceptos básicos y avanzando poco a poco hacia ejercicios más completos. También hemos trabajado con el DOM para modificar páginas web desde JavaScript y con ES6 para utilizar una sintaxis más moderna.

Gracias a estos ejercicios hemos reforzado la lógica de programación, la organización del código y el uso de herramientas habituales como Visual Studio Code y la consola del navegador.
